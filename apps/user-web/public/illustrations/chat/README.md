# Transactions hub illustrations

Hand-authored SVGs for Member web `/chat` ("Giao dịch của bạn", Lật lại). Original
work made for this page; not traced or copied from other art. Palette follows the
brand wine (`#5c0202`, `#7c1a17`), butter gold (`#f4cb67`, `#f6e0a8`), exchange
green (`#2e6b52`) and cream (`#fffcf5`).

| File | Use |
| --- | --- |
| `letters.svg` | Header: two speech bubbles trading over an open book, a price tag and swap arrows |
| `empty-inbox.svg` | Empty list: an open envelope with a book peeking out |

Both are decorative (`alt=""`, `aria-hidden`). The page backdrop is the shared
`AccountBackdrop` component (gradients only).
