# My auctions illustrations

Hand-authored SVGs for Member web `/my-auctions` (Lật lại). Original work made for
this page; not traced or copied from other art. Palette follows the brand wine
(`#5c0202`, `#7c1a17`), butter gold (`#f4cb67`, `#f6e0a8`), wood (`#b9814f`,
`#d9a873`) and cream (`#fffcf5`).

| File | Use |
| --- | --- |
| `paddle.svg` | Header: a raised bidding paddle over a book stack, with a lot ticket |
| `parcel.svg` | "Sách chờ đăng phiên" card corner: drop-off parcel, lot tag, inspection tick |
| `empty-rack.svg` | Empty list: a shelf with dashed spaces for the next lots |

All are decorative (`alt=""`, `aria-hidden`). The backdrop reuses
`../auction-create/pattern.svg`.
