# Book desk background artwork

## Autumn book desk, reused for Chat —19/10/2026

`autumn-book-desk.webp` restores the exact77KB/1672×941px background from
commit `6394dc4`, approved by the owner on18/10/2026 for the posting page.
The soft3D autumn illustration was produced with the built-in image generation
tool and encoded as WebP quality88. The owner requested its reuse on `/chat`
and individual chat rooms after the posting page returned to the archival desk.
It is a decorative fixed background, never listing media. No repainting or new
generation was performed for Chat; the separate penguin tile is not part of it.

## Archival desk retained on Sell

`archival-desk.webp` is a compressed derivative of the existing project asset
`apps/user-web/public/ĐangAnh_BG.png`, retained from Tuấn Minh's posting design
at commit `36cb0c03210725c585a7518551c2ac65de92a328`.

The project owner approved reuse for the blended posting page on11/10/2026.
No artwork was generated or repainted: Sharp resized to2200px wide without
enlargement and encoded WebP at quality84. Original PNG remains unchanged.
The derivative is decorative only, never a listing photograph or user content.

22/10/2026: the shared Home/Search book card reuses this exact derivative as its
warm paper cover-stage background to follow the owner's supplied reference.
The real listing photograph stays separate and fully contained above it. No
pixels were generated or repainted for this reuse; source and provenance remain
the same.

External artist/license attribution was not supplied with the legacy asset;
the Git origin records provenance, not proof of a third-party commercial license.
Confirm that permission before distributing outside the project demo.
