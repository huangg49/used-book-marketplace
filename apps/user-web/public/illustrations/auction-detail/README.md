# Auction detail illustrations

Hand-authored SVGs for Member web `/auctions/:id` (Lật lại). Original work made
specifically for the auction detail & bidding page; not reused from other pages.
Palette follows the brand wine (`#5c0202`, `#7c1a17`), gold (`#f4cb67`, `#f6e0a8`),
wood (`#b9814f`, `#d9a873`), and cream (`#fffcf5`, `#fbf4e8`).

| File | Use |
| --- | --- |
| `gavel-crest.svg` | Header crest beside the auction title and badges |
| `empty-bids.svg` | Empty state of "Diễn biến giá" before the first bid |

All are decorative (`alt=""`, `aria-hidden="true"`).
