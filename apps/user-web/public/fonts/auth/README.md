# Auth typefaces

Locally hosted original Google Fonts variable TTFs, downloaded 11/10/2026.
- BricolageGrotesque.ttf: ofl/bricolagegrotesque/BricolageGrotesque[opsz,wdth,wght].ttf
- Caveat.ttf: ofl/caveat/Caveat[wght].ttf

Source: https://github.com/google/fonts (main). Original filenames above.
Both use SIL Open Font License 1.1; their OFL texts are kept here (whitespace normalization only).
No conversion/subsetting. Bricolage is scoped to Auth headings and the receipt
stamp; Caveat to margin annotations, librarian notes and server errors.
Functional labels/inputs retain the project's Be Vietnam Pro. Fonts are served
locally, with no runtime Google Fonts request introduced by this Auth change.
