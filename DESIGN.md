# Design System: Lật lại

## Overview

**Creative North Star: "Tiệm sách nhiều màu"**

Member web pairs the owner's wine-red owl and lettering with warm paper, tall display type and colored grounds for complete book covers. Discovery is lively; listing facts and task controls stay direct, readable and quieter than the covers. This records the world built after the owner's replacement decision on 10/10/2026, using the [surface contract](apps/user-web/.impeccable/surfaces/apps-user-web-src-pages-booksearchpage-tsx.md) and [PRODUCT](PRODUCT.md), rather than the superseded green web sketches.

The implemented web slice is Home, Search, Detail, Login, Sell, Account, Register, shared Header/BookCard/ConfirmDialog and MainLayout/DashboardLayout. Auth owns a central three-sheet library file over the original wine-tinted bookstore photograph, with the original wine logo on paper, a pencil annotation and a separate home link, apart from the shared Member Header. Login, Register and password recovery share that scene and now connect real public account-auth commands; OTP verification/recovery uses the approved Brevo sender or a local demo mailbox. Sell owns its paper task desk and five existing steps. Account owns a real owner-listing shelf and read-only identity inside compact personal navigation. The approved inner-page illustration extension adds Sell's submission receipt, Account's initial empty shelf and Auction's introduction, preserving the established wine/cream penguin world. Auction's filters, live query, cards and remaining body retain their legacy recipes; other forms and chat are outside this extension. React Native retains its separate green Be Vietnam Pro system; its source/tests were not changed by this web build. Flutter remains scaffold. These tokens describe implementation, not human acceptance or a closed release gate.

Search refined11/10 preserves the compact wine title/search band,264px rail and compact cover recipe. The rail is transparent and borderless; filter fields use shelf ground and a bottom edge, price bounds stack at full width, and a full-width Apply sits above the quiet underlined reset. Live and DEV preview share category/subcategory and context-dependent disclosure groups through CatalogClassificationFields. The12/10 compact-dropdown extension opts Search category/subcategory and edition language into searchable desktop comboboxes with a bounded paper list; at900px and below they retain real native selects. Long filters scroll with the page; only a complete rail that fits is sticky. The named native dialog has a scrolling form body, separate Apply/Reset footer and drafts retained across close/reopen. Classification, edition language and separate sale/exchange bounds commit to URL criteria;counts cover only this page. Preview97 Open Library editions remain labelled sample data,separate from live API behavior. Scoped170ms boundary/label feedback and140ms popup entry remain under either OS motion preference; unchanged Search controls retain their existing motion handling, and shared catalog-card depth follows its scoped owner-approved exception.

**Key Characteristics:**

- Wine-and-cream identity with orange, yellow and mint discovery accents.
- Anton for expressive headings; Be Vietnam Pro for book facts and actions.
- Whole covers on colored grounds; unboxed metadata and separately labelled prices.
- Original owner logo and sourced decorative imagery, distinct from listing photographs.
- Responsive web recipes and a separately preserved React Native implementation.

## Colors

The web palette moves from a dark wine shell to warm paper shelves and soft cover grounds.

### Primary

- **Logo wine** (`shop-wine`): header, footer, primary actions, prices and selected photo controls.
- **Warm cream** (`shop-cream`): text and light actions against wine; focus outline on wine surfaces.
- **Wine hover** (`shop-wine-hover`): primary action hover on Detail, Login and the dialog.

### Secondary

- **Bookshop orange / shelf yellow / mint** (`shop-orange`, `shop-yellow`, `shop-mint`): search action and discovery grounds; yellow also emphasizes hero words and search hover. Home's budget pair uses shelf yellow and `cover-peach`; its exchange section uses the lighter `cover-sage` ground with scoped `shop-exchange-ink` introduction/link text.
- **Sand / sage / peach / lilac** (`cover-*`): the four recurring card cover grounds. They alternate by position, not listing condition, seller trust or availability.
- **Error rust** (`shop-error`): validation/error text and the dialog's danger variant.

### Neutral

- **Web paper / ink / muted** (`shop-paper`, `shop-ink`, `shop-muted`): canvas, reading text and secondary metadata. Home's discovery field and state panels use `shop-shelf`, with paper category/catalog panels; the gallery and descriptive condition labels use `detail-ground`.
- **Divider / control boundary** (`shop-line`, `shop-control`): quiet grouping versus the stronger Login, price-input, sort and radio boundary treatments.
- **Detail label ink** (`detail-label-ink`): descriptive condition/mode text on the photograph ground; this is a scoped factual label role.

Root isolation and pointer-events:none keep it behind controls; it disappears with the Sell route. Opaque `shop-paper` keeps the form and preview readable. The horizontal active-step indicator uses `shop-wine` with cream text and a cream number disc; `detail-ground` remains the upload and contained-photo ground. `sell-action-hover` is the primary hover. Fields, dashed upload boundary, native file-selector button and mode rows reuse `shop-control`; dividers keep `shop-line`, inline errors use `shop-error`. These roles apply only to Sell.
- **Search scope:** the page binds the existing `shop-wine-hover`, `shop-shelf` and `shop-error` values locally, matching the existing canonical palette where global CSS lacks these roles. Native filter selects and idle price presets use shelf ground; the rail and desktop footer stay transparent. Apply hover and price error keep their explicit source colors without adding palette tokens.
- **Auth scope:** `auth-paper` is the reader-card ground, `auth-back-sheet` the rear leaf and existing `cover-sand` the middle leaf. `auth-note` softens the annotation source; `auth-photo-tint` is the deep translucent wine layer over the photograph. These are local Auth roles; shared wine/cream/ink/muted/line/control colors stay unchanged. Auth binds `--auth-error` to existing `shop-error` for handwritten errors and the success stamp; focused text fields keep transparent paper and a stronger wine underline.
- **Google entry preview (11/10):** Login alone places a thin “hoặc” divider and full-width48px white Google button before registration. Native disabled/type=button, explicit “Sắp có” description; no SDK/OAuth/session changes. Official local Google G retains its colors/proportions and source provenance. Vendor white/#747775 stroke/#1f1f1f text are scoped exceptions (three detector color advisories), not shop tokens. Existing shop font is retained for this UI preview; recheck Google font/branding requirements when implementing sign-in. Compact laptop spacing fits1280×720;390/320px mobile stays in normal flow. Source/browser finish pass found no scoped blocker;69existing tests/build/lint passed with known warnings. OAuth, physical mobile, screen-reader speech, human acceptance and CI were not tested.
- **Account scope:** the task canvas reuses the existing `sell-desk-ground` value; shelf and profile use `shop-paper`, contained photograph grounds and sidebar selection reuse `detail-ground`, and quiet row/section rules use `shop-line`. The Account disclosure and profile bind the existing `cover-sand` role locally for name initials/selection; disclosure hover binds the existing `shop-shelf` role. Wine text communicates actual state and separately labelled values; it does not introduce trust or wealth indicators. Register and recovery reuse the Auth-local material palette.
- **Incumbent RN colors** (`rn-*`): forest action/heading, paper canvas, surface navigation, shelf canvas, ink, muted, rust condition text, input border, divider and selected-navigation surface. These are preserved from [RN theme](apps/mobile-react-native/src/core/ui/theme.ts) and [brand identity](packages/brand/v1.1/identity.tokens.json), not applied to the new web slice.

**The Ground Is Not Status Rule.** Colored cover grounds are decorative; communicate condition, prices and reservation state in real text from the listing.
